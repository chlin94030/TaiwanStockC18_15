## 本次修復

1. 每日補抓近一個月日線，即使原股票已經有五年快取，也要補上最新收盤。
2. 官方 TWSE/TPEx EOD 日期按來源實際日期核對；額外使用證交所 FMTQIK 加權指數日結表備援。
3. 若兩市與指數新收盤已存在快取，但官方來源仍舊，標為 **暫定研究**，不當作官方同步或可買。
4. 即使官方資料暫時沒核對，仍可顯示已存在的**舊日期五日歷史報酬試算**，不隱藏為假空值；沒有有效歷史模型時仍顯示「—」，絕不捏造。
5. 盤後舊快照不能發出可執行買點，個股診斷及其他入口亦適用；更新工作完成但日期未前進會明確標註失敗原因。
6. 平日 17:00 後第一次開啟且基準落後，若當日晚間尚未啟動過掃描，自動排入一次背景更新；上午更新不會阻擋晚上更新。亦可手動按更新。

## 部署後確認

- 交易日收盤後按「背景更新日線模型」，等待狀態出現「完整模型更新完成」或「暫定研究／仍未更新」的清楚理由。
- 「今日決策」看 **上市、上櫃官方原始日期**與**統一模型日**；若模型日仍落後，展開「資料來源與同步狀態（進階）」看錯誤。
- **尚未核對**的研究估計不得當成下個交易日可買指令；報酬證據必須是模型真實算得出才顯示。
- 若 Streamlit Cloud 重啟後丟失 SQLite，初次啟動需要重新建置五年行情；長期可靠運作須考慮持久化資料。
